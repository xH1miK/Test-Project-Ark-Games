# План работ

Тестовое задание Royal Ark Games (Playable Ads Creator). Cocos Creator 3.8.8 → один HTML ≤ 5 МБ + отчёт об AI-процессе с таймлайном.
Сдача: **вс 4.10.2026**, пн 5.10 — резерв. Контрольная точка: **ср 30.09 — игра проходится от начала до конца**.

## Объём

Обязательно: трактор + апгрейд до 2 уровня · шарики → ковш → шредер → монеты · туториал стрелкой · базовые звуки · открытие ворот (финал).
Выбрано сверху: **сочность** (полёт монет, валы шредера, «пружинка» апгрейда, отъезд камеры, частицы у ворот).
Не делаем: интро-пролёт, пэкшот/CTA, второй этаж, золотые шарики.
Стиль: как в примере + свой полиш.
