# GDD — наша версия

Референс: `docs/reference-example-teardown.md` (разбор примера). Здесь — то, что делаем мы. Все числа живут в `assets/scripts/core/Config.ts`.

## Суть

Изометрическая 3D-сцена: пещера, ковёр из бирюзовых шариков, трактор с ковшом. Игрок ведёт трактор плавающим джойстиком,
собирает шарики, сдаёт их в шредер за монеты, прокачивает трактор и открывает ворота. Портрет и альбом, текст в игре — английский.

## Сценарий

1. Старт: камера на тракторе, стрелка показывает на шредер через поле шариков. Джойстик появляется по касанию.
2. Трактор въезжает в шарики — ковш набирает до **8** (T1). Полный ковш толкает шарики как отвал.
3. Зона шредера (квадрат ±3.5; в зоне должен быть центр машины — круга тела, у длинного T2 пивот до зоны не достаёт): груз улетает дугой, **+2 монеты/шарик**, монеты летят в счётчик. Затолканные в «горло» шредера шарики тоже оплачиваются.
4. После первой сдачи «выпрыгивает» площадка **UPGRADE 100** (шарики расталкиваются из-под неё).
5. Трактор стоит на площадке (±3.1) — монеты перетекают на неё за ≤ 1.55 с, цифра считает вниз, частичная оплата сохраняется.
6. Оплачено → **трактор T2**: модель Tractor2, «пружинка» 0.55→1 за 0.35 с, пыль, звук, камера отъезжает ×1.2, ковш **60**, скорость 3.6 → 8.4. Площадка показывает MAX.
7. Площадка **UNLOCK 300** у ворот видна с начала. Оплачено → занавес/ворота открываются (0.85 с), искры, звук покупки, площадка исчезает.
8. **Финал:** короткий праздничный эффект и надпись, управление выключается.

## Туториал

- Стрелка у трактора (над землёй, впереди на ~3.2) поворачивается к цели. Указатель подпрыгивает над целью.
- Шаги: **Sell** (цель — шредер) → **Upgrade** (площадка) → **Gate** (площадка ворот) → **Done**.
- Если монет 0 и площадка не оплачена — стрелка ведёт к шредеру. Летящие монеты не считаются.

## Цифры (стартовые, тюним по ощущениям)

| Параметр | Значение |
|---|---|
| Шарик: радиус / цена | 0.275 / 2 монеты |
| Шариков на поле | ~1500 (в конфиге), без респауна |
| Трактор T1: скорость / ковш / радиус тела | 3.6 / 8 / 1.2 (круг на 0.55 впереди пивота — над всей машиной с ковшом; поворот вокруг гусениц) |
| Трактор T2: скорость / ковш / радиус тела | 8.4 / 60 / 1.8 |
| Поворот / разгон / торможение | 240°/с / 14 / 22 |
| Цены: апгрейд / ворота | 100 / 300 |
| Камера | смещение (17.08, 24.15, 17.08), pitch −45, yaw 45, сглаживание 0.18 с, зум T2 ×1.2 за 0.5 с |
| Джойстик | радиус 220, кнопка 80, мёртвая зона 0.08, плавающий; в покое внизу по центру (300 над краем), прозрачность 140/255, возврат 0.25 с; касание вне кнопки переносит базу под палец |
| Полёт монет | 0.45 с, ≤ 6 спрайтов на выплату, ≤ 20 одновременно |

## Звуки

Музыка (цикл, тихо) · мотор (цикл, пока едет) · щелчки шариков в ковш · хруст шредера (цикл) · монеты в счётчик · монеты на площадку ·
апгрейд · покупка/открытие ворот · финал. Разблокировка по первому касанию, кнопка mute внизу слева.

Решения пользователя 29.09 (S1): **музыка — вариант C**, тихий эмбиент-пэд (цикл 12 с, четыре аккорда по 3 с и редкие колокольчики); **финал — как в примере**: при оплате ворот играют «покупка» (0,65) и «свист ворот» (0,55, не чаще раза в секунду; в примере это `GateOpen`, в teardown §7 он был пропущен); **мотор — как в примере**: цикл 0,04 включается, пока трактор едет, с плавным затуханием 0,15 с (питча в Cocos нет).
Звуки синтезируются кодом (`tools/audio/`), громкости и интервалы — из таблицы примера (teardown §7). «Оплата площадки» проигрывает те же пять монет-клипов по нарастающей высоте (вариант растёт с заполнением цены), а не отдельные файлы.

## UI

Счётчик монет справа сверху (плашка + иконка + число с «пуншем»), кнопка звука слева снизу, плавающий джойстик,
плашки площадок на земле (иконка + цена), табличка цены над воротами. Макет 1280×2276 портрет, масштаб под любое соотношение.

## Не делаем

Интро-пролёт, пэкшот/CTA, второй этаж, золотые шарики, конвейер, дальняя дверь.
